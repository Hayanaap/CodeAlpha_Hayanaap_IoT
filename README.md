# CodeAlpha_Hayanaap_IoT

CodeAlpha IoT Internship

This repository contains the projects and tasks completed during my CodeAlpha Internet of Things (IoT) Internship. The tasks provide practical experience in IoT concepts, Arduino programming, simulation, and real-world IoT applications.

Completed Tasks

Task 1 – Research Report: IoT in Real Life

Topic: Smart Industrial Automation

This task focuses on the role of IoT in Smart Industrial Automation. The report explains how sensors, connected devices, and IoT technologies can be used to monitor industrial systems, collect real-time information, automate processes, and improve overall efficiency and safety.

Submission:

- Research report in PDF format

---

Task 2 – Sensor-Based Simulation

This task demonstrates a basic sensor-based IoT simulation using Tinkercad. An Arduino UNO is used to control an LED through an electronic circuit and Arduino programming. The simulation provides practical understanding of circuit connections, programming, and basic IoT concepts.

Tools and Components Used:

- Tinkercad
- Arduino UNO
- LED
- Resistor
- Arduino Programming

Submission:

- Circuit simulation screenshots
- Arduino source code
- Code explanation

---

Task 4 – Mini Project: IoT Case Study

This task presents a mini project based on an IoT case study. It demonstrates how IoT technology can be applied to solve a real-world problem using sensors, microcontrollers, and connected systems. The project includes the design, implementation, and explanation of the proposed IoT solution.
